# Leitura Confortável

Leitor responsivo de artigos acadêmicos traduzidos. A aplicação oferece:

- biblioteca de artigos;
- modo claro e escuro;
- paginação independente para desktop e celular;
- ajuste do tamanho do texto;
- destaques pesquisáveis;
- progresso e destaques sincronizados entre dispositivos.

O primeiro conteúdo é uma edição traduzida e adaptada de Abdi e Amrit (2021), publicada originalmente na PeerJ Computer Science sob licença CC BY 4.0.

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

O projeto usa Vinext/Next, Cloudflare Workers e D1. A publicação é gerenciada pelo ChatGPT Sites.
